# Sample saves

All files here are **synthetic**. They're generated by `npm run samples` using the same encoders the engines use, but none of them comes from a real game.

| File | Produced by | Shape |
| --- | --- | --- |
| `renpy8-1-1-LT1.save` | `tools/make_renpy_samples.py` | Ren'Py 8 slot: ZIP_DEFLATED, `log` = protocol‑5 pickle of `(roots, RollbackLog)`, with a fake `signatures` file |
| `renpy-legacy-protocol2.save` | same | Ren'Py 7-style protocol‑2 pickle, unsigned |
| `renpy-protocol0.save` | same | Text protocol‑0 pickle (oldest Ren'Py) |
| `renpy-persistent-unsigned` | same | `zlib.compress(pickle(Persistent))` |
| `renpy-persistent-signed` | same | The same, with a signature trailer (opens read-only) |
| `rpgmaker-mv-file1.rpgsave` | `tools/make-samples.mjs` | `LZString.compressToBase64(JsonEx JSON)` |
| `rpgmaker-mz-file1.rmmzsave` | same | `pako.deflate(json, {level: 1})` as a binary string, written as UTF-8 (MZ `StorageManager`) |
| `sugarcube-the-lantern-road.save` | same | SugarCube 2 `Save.export` (LZString Base64 JSON) |
| `sandbox-base64.txt` / `sandbox-plain.json` / `sandbox-gzip.save` | same | Generic HTML5 sandbox save in three encodings |
| `gamemaker-save.ini` | same | GameMaker-style INI with quoted reals |
| `storage-dump-example.json` | same | Storage Bridge export with localStorage (RPG Maker MV and Base64 saves) and IndexedDB (a Ren'Py web save as bytes) |

The Ren'Py samples use stand-in classes registered under Ren'Py's module names (`tools/renpy_fixtures.py`), so the opcode structure matches a real save: class references, `NEWOBJ`/`REDUCE`, `BUILD` with `__dict__`, memoized strings, and framing. The actual Ren'Py classes aren't needed, because SaveForge never instantiates classes.
