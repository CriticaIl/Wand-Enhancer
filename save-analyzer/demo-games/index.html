SaveForge demo games

Small original games for trying the trainer. Each one imitates the public JavaScript API shape of one engine so the matching trainer integration can be tested. They are not those engines, and they contain no assets or code from other games.

  • Neon Courier: canvas game with plain global state (generic live editing)
  • Lantern Tale: story using the SugarCube.State / Engine.show() API shape
  • Crystal Quest: RPG using RPG Maker's $gameParty / DataManager API shape
  • Tap Miner: clicker using Construct 2's cr_getC2Runtime().all_global_vars
  • Ruins (web): keeps a Ren'Py-format save in IndexedDB (storage-only: Apply & Reload)

To open the trainer on these pages, use the SaveForge app's Game tab (same site) or the trainer bookmarklet.
